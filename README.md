# 施工中場所火災表自動產製工具

將制式「臺北市政府消防局場所紀錄表」PDF 依固定規則擷取資料，填入內建的「施工中場所火災－消防安全管理及應變執行情形表」Word 制式表。

**不使用 AI、不呼叫外部 API。**

## 給一般使用者

到 GitHub Releases 下載：

`消防安全表自動產製工具.exe`

電腦不需要安裝 Python。雙擊 EXE 後選擇 PDF，再按「產生 Word」即可。

也可以把 PDF 直接拖到 EXE 圖示上，程式會自動讀取該 PDF。

## v0.1 固定擷取規則

- `公司商號` + `市招` → Word「場所名稱」
- `場所地址` → Word「場所地址」
- `安全查察` 中最新一筆「消防設備」 → Word「消防安全設備」
- `檢修申報` 中最新有效申報列 → Word「消防安全設備檢修申報」
- `防護計畫書製定(變更)日期` → Word「防火管理」
- `防焰物品` → Word「防焰物品」

火災時間、火災位置、原因分析、火災當日設備動作、119 通報、疏散等資料不由場所紀錄表推定，會保留制式預留文字，待火災發生後補填。

PDF 沒有提供的資料，程式不推測、不沿用舊案資料。

## 開發者自行打包

Windows 安裝 Python 3.11/3.12 後執行：

`build_exe.bat`

輸出：

`dist\消防安全表自動產製工具.exe`

GitHub Actions 亦會自動在 Windows 環境打包並更新 `v0.1.0` Release 的 EXE。
